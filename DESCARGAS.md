# 📦 ORGANIZADOR - DESCARGAS SIN PYTHON REQUERIDO

## ✨ ¿Qué es esto?

Ejecutables compilados de Organizador que **funcionan sin Python instalado**. Todo incluido en un solo archivo.

---

## 🚀 DESCARGA E INSTALACIÓN

### 🪟 **Windows**
```
Organizador-Windows.exe (60 MB)
```
1. Descarga `Organizador-Windows.exe`
2. Haz doble clic para ejecutar
3. ¡Listo! No necesita Python ni instalación

### 🐧 **Linux**
```
Organizador-Linux-standalone.tar.gz (60 MB)
```

**Opción A - Instalación automática:**
```bash
tar -xzf Organizador-Linux-standalone.tar.gz
cd Organizador-Linux
./install.sh
organizador    # Luego ejecuta con este comando
```

**Opción B - Ejecutar directamente:**
```bash
tar -xzf Organizador-Linux-standalone.tar.gz
./Organizador-Linux/Organizador
```

### 🍎 **Mac (portable)**
```
Organizador-Portable-Standalone.zip (60 MB)
```
1. Descarga el ZIP
2. Descomprime
3. Abre terminal en la carpeta
4. `./organizador.sh` o `./Organizador`

## ⚠️ SOLUCIÓN DE PROBLEMAS

**En Windows no se abre el .exe**
- Intenta: Click derecho → Ejecutar como administrador
- O descargar desde GitHub Releases

**En Linux dice "permiso denegado"**
```bash
chmod +x Organizador-Linux/Organizador
./Organizador-Linux/Organizador
```

**En Mac se abre pero se cierra inmediatamente**
```bash
chmod +x organizador.sh
./organizador.sh
```
