❌ "Python not found" (Windows)
  → Descargar desde https://www.python.org/downloads/
  → Reinstalar con "Add Python to PATH" marcado

❌ "Command not found: python3" (Linux/macOS)
  → Linux: sudo apt install python3
  → macOS: brew install python3

❌ Aplicación no inicia
  → Verificar: python3 --version (debe ser 3.9+)
  → Revisar permisos: chmod +x run.sh install.sh
  → Ver logs: tail -f app.log

❌ Caracteres especiales rotos (ñ, €, etc)
  → La aplicación usa UTF-8 automáticamente
  → Si persiste, actualizar locales: sudo locale-gen es_ES.UTF-8
